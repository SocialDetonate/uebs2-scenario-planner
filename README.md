## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Faction Planner** | Plan unit counts and types per faction for your battle |
| **Terrain Notes** | Log terrain and environment settings for your scenario |
| **Special Conditions** | Plan special modifiers like giants, berserkers or weather |
| **Scenario Library** | Save named battle scenarios to replay or share with others |
